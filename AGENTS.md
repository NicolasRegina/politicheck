# Agent Instructions

## Project Overview

**Politicheck**: Plataforma cívica e informativa de alto tráfico para el periodo electoral en Argentina. Compara el sesgo y encuadre mediático de las noticias del día mediante agregación de feeds RSS oficiales y audita las promesas de campaña de los candidatos.

Consulte siempre [CONTEXT.md](./CONTEXT.md) para respetar la terminología de dominio y las decisiones registradas en [docs/adr/](./docs/adr/).
