# Local Markdown Issue Tracker

Issues for this repository are tracked as markdown files under `.scratch/<feature>/issues/`.

## Structure

```
.scratch/
└── <feature>/
    └── issues/
        ├── 001-issue-title.md
        ├── 002-issue-title.md
        └── ...
```

## Issue Format

Each issue file contains:
- Title and description
- Clear acceptance criteria
- Blocking dependencies (if any)
