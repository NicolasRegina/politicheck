# 0002: Identidad de Marca y Estrategia de Dominios (Politicheck)

## Contexto
El proyecto necesita un nombre de marca que comunique rigor cívico, neutralidad y seriedad política, al mismo tiempo que abarque tanto la comparación de cobertura mediática como la auditoría de promesas electorales. Se evaluó "Politifact" y "Politicheck", junto con las extensiones territoriales `.ar` y `.com.ar`.

## Decisión
1. **Nombre de Marca**: Se adopta **Politicheck**.
   - Se descarta "Politifact" para evitar conflictos legales de propiedad intelectual y ciberocupación con la marca registrada estadounidense *PolitiFact* (Poynter Institute).
   - "Politicheck" combina con claridad el foco político y la verificación objetiva sin connotación partidaria.
2. **Estrategia de Dominio**:
   - Para Google / SEO no existe diferencia técnica entre `.ar` y `.com.ar` (ambos geolocalizan en Argentina con idéntico valor).
   - Se registró **`politicheck.com.ar`** (familiar para el usuario tradicional) y **`politicheck.ar`** (marca moderna y concisa), apuntando uno como dominio canónico y el otro mediante redirección 301.
